
# Country Explorer & Travel Planner

## Setup

1. Create a Firebase project.
2. Enable:
   - Authentication (Email/Password)
   - Firestore Database

3. Replace the Firebase config inside `app.js`.

4. Run locally with VS Code Live Server
OR open index.html directly.

## Features

- Firebase Login/Register/Logout
- Password Reset
- Country Search
- Region Filter
- Sorting
- Country Details
- Live Weather
- Interactive Leaflet Map
- Save Favorites to Firestore
- Responsive Layout

## APIs Used

- REST Countries API
- Open-Meteo API
- Firebase
- OpenStreetMap + Leaflet
